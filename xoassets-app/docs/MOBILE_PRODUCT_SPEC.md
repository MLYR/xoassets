# 移动端产品范围 AI 约束

## 1. 产品定位

`xoassets-app` 是 XOAssets / 小〇财迹的 React Native 移动端 App。

定位：

```text
个人资产驾驶舱 + 记账 + 账户管理 + 投资管理 + 预算管理 + AI 财务复盘
```

移动端第一版重点是高频个人使用场景，不做后台管理系统。

## 2. 第一版目标

第一版优先完成：

| 模块 | 目标 |
|---|---|
| 登录注册 | 能登录、注册、恢复登录态、退出登录 |
| 首页 | 展示总资产、净资产、资产变化、最近记录 |
| 记账 | 新增、编辑、删除普通流水；最近记录可跳转到记账日历 |
| 账户 | 查看账户、新增账户、编辑账户、余额修正 |
| 投资 | 查看持仓、录入投资交易、刷新行情 |
| 预算 | 查看月度预算和分类预算 |
| 报告 | 查看模板化 AI 财务报告 |
| 设置 | 主题、金额隐藏、退出登录、版本信息 |

## 3. 第一版不做

禁止越阶段实现：

- 银行卡自动同步。

## 4. 资产口径补充

- 首页总资产优先使用 `/api/snapshots/latest` 的快照口径。
- 基金金额买入的 `PENDING_CONFIRM` 在途金额属于投资资产，投资总览需单独展示。
- 支付宝自动同步。
- 微信自动同步。
- 券商自动同步。
- 离线数据库。
- 离线同步队列。
- 社交功能。
- 复杂后台管理。
- 投资买卖建议。
- 真实 AI 聊天助手作为首页核心。
- Web 页面套壳。

## 5. 页面优先级

推荐阶段顺序：

```text
登录 / 注册
首页资产驾驶舱
记账与流水
账户管理
投资管理
预算管理
AI 报告
设置
附件上传
图表分析
上架准备
```

Codex 只能实现用户明确指定的阶段，不允许一次性做完整 App。

## 6. 首页信息架构

首页优先展示：

1. 用户问候与快捷操作。
2. 总资产 / 净资产核心卡片。
3. 较昨日或较月初变化。
4. 现金资产与投资资产摘要。
5. 当月收入 / 支出 / 预算使用率。
6. 最近 3-5 条流水。
7. AI 今日复盘入口。

首页最近记录的「查看全部」应跳转到记账页日历并默认定位当天；列表项点击应可直接进入对应日期的记账日历。

首页禁止：

- 堆大量图表。
- 把所有模块入口都塞满首屏。
- 用 mock 金额冒充真实接口数据。
- 把收益口径统一叫“今日收益”。

## 7. 记账规则

记账页面必须支持：

- 支出。
- 收入。
- 转账。
- 退款，后续阶段支持。
- 分类选择。
- 账户选择。
- 金额输入。
- 日期时间输入。
- 备注。

规则：

- 流水金额不能为空。
- 账户不能为空。
- 分类按后端返回展示。
- 转账不计入收入支出。
- 预算使用额以后端统计为准。
- 记账页日历支持月份左右滑动切换。
- 记账页统计页的趋势图、分类排行和明细排行支持点按查看明细。
- 记账页明细详情默认按两列展示，提升真机阅读效率。

## 8. 投资规则

投资模块必须遵守业务口径：

- 基金展示昨日收益。
- 股票展示今日收益。
- 虚拟货币展示 24h 收益。
- 总投资不要强行合并为今日收益。
- 市值、成本、盈亏以后端返回字段为准。
- 不允许移动端反算收益。
- 不允许提供买卖建议。

## 9. AI 报告规则

AI 报告当前是财务复盘，不是投资顾问。

允许：

- 总结资产变化。
- 总结收支结构。
- 提醒预算风险。
- 给出记账习惯建议。

禁止：

- 推荐买入某股票、基金、币种。
- 预测收益。
- 生成夸张、恐吓式财务评价。
- 泄露用户敏感信息。

## 10. AI 执行规则

Codex / AI 做产品功能时必须：

1. 先读 `xoassets-app/AGENTS.md`。
2. 再读 `xoassets-app/MOBILE_APP_PHASES.md`。
3. 再读本文件。
4. 不做未指定阶段。
5. 不新增与当前阶段无关页面。
6. 不引入未确认依赖。
7. 不修改后端业务口径。
8. 不用 mock 替代真实接口，除非用户明确要求。
9. 无接口时必须说明缺口，而不是编接口。
