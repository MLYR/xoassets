# XOAssets App React Native 开发阶段约束

## 1. 总体规则

- 所有阶段必须按顺序推进。
- 每次只能执行用户指定阶段。
- 不允许越阶段实现。
- 不允许一次性实现所有业务。
- 不允许未确认就引入新依赖。
- 不允许修改与当前阶段无关的模块。
- UI 规范查看 `docs/MOBILE_UI_DESIGN_SYSTEM.md` 和 `docs/SHADCN_UI_STYLE_GUIDE.md`。
- 图标规范查看 `docs/MOBILE_ICON_ASSETS_GUIDE.md`。
- 接口规则查看 `docs/MOBILE_API_INTEGRATION.md`。

## 阶段 0：基础约束与项目准备

### 目标

建立项目开发规则，防止 Codex 乱改、乱删、越阶段实现。

### 任务

```text
扫描当前仓库结构
确认 React Native 项目位置
确认移动端目录为 xoassets-app
建立 AGENTS.md
建立 MOBILE_APP_PHASES.md
建立 README.md
建立基础 .gitignore
确认 Node / pnpm 可用
确认 Expo 启动方式
```

### 禁止

```text
不要删除后端代码
不要删除 Web 代码
不要删除文档
不要一次性生成完整业务
```

### 验收标准

```text
项目目录清晰
文档存在
Codex 后续任务有约束依据
```

### 目标

建立真实登录注册能力和基础 API 通信能力。

### 任务

```text

保存 refreshToken，若后端支持
请求自动带 Token
401 自动处理
退出登录
登录态恢复
基础错误提示
基础 Loading 状态
```

### 推荐接口

```text

POST /api/auth/register

```

### 验收标准

```text
可以登录
可以注册
可以退出

```
