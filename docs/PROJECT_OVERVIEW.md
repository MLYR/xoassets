# 项目概览

## 1. 项目定位

XOAssets / 小〇财迹 是个人资产管理与财务复盘工具，核心能力包括：

- 账户管理
- 分类管理
- 收支记账
- 转账
- 首页资产驾驶舱
- 图表统计
- 投资持仓维护
- 预算管理
- 资产目标
- AI 模板化财务报告

## 2. 仓库结构

```text
xoassets-server   Java 17 + Spring Boot 3 后端
xoassets-web      Vue3 + TypeScript + Vite Web 管理端
xoassets-mobile   Flutter 新版移动端 App
xoassets-app      uni-app + Vue3 + Pinia 旧移动端 App
```
