# 项目概览

## 1. 项目定位

XOAssets / 小〇财迹 是个人资产管理与财务复盘工具。

核心能力：

- 账户管理
- 分类管理
- 收支记账
- 转账
- 首页资产驾驶舱
- 图表统计
- 投资持仓维护
- 预算管理
- 资产目标
- AI 模板化财务报告

## 2. 仓库结构

```text
xoassets-server   Java 17 + Spring Boot 3 后端
xoassets-web      Vue3 + TypeScript + Vite Web 管理端
xoassets-app      React Native 新版移动端 App
```

## 3. 当前重点

### 后端

后端是业务和数据口径权威，覆盖：

- 登录注册
- 账户
- 分类
- 流水
- 首页统计
- 基础图表统计
- 资产快照
- 投资持仓维护
- 行情刷新
- 预算管理
- 资产目标
- AI 报告模板生成

### Web 前端

Web 端继续使用：

- Vue 3
- Element Plus
- ECharts
- Pinia
- Vue Router
- `xo-design` tokens

### React Native 新版移动端

新版移动端使用 React Native 技术栈，从零开始实现：

- App 壳子
- 登录注册
- 首页资产驾驶舱
- 记账
- 账户管理
- 投资管理
- 预算管理
- AI 财务报告
- 设置与系统能力

## 4. 第一版功能边界

### 必须优先完成

- 登录注册
- 账户管理
- 分类管理
- 收支记账
- 转账
- 首页仪表盘
- 图表统计

### 建议完成

- 投资持仓手动维护
- 每日汇总
- AI 日报
- 预算管理
- 资产目标

### 第一版不建议完成

- 银行卡自动同步
- 支付宝自动同步
- 微信自动同步
- 券商自动同步
- 投资买卖建议
- 社交功能
- 复杂后台管理
- 移动端离线同步
- 移动端本地数据库
