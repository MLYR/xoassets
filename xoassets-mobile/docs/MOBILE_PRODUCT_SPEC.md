# XOAssets Mobile V2 产品与页面规范

## 1. 项目定位

```text
个人资产驾驶舱 + 记账 + 账户管理 + 投资管理 + 预算管理 + AI 财务分析
```

目标平台：

- Android
- iOS

不考虑：

- Web 端复用
- 小程序
- uni-app
- WebView 套壳

## 2. 页面结构

### Splash 页面

职责：

```text
展示 App 名称 / Logo
检查登录态
跳转 Login 或 Main
```

### 登录 / 注册页面

职责：

```text
登录表单
注册表单
登录状态
注册状态
错误提示
密码显隐
协议勾选
验证码倒计时
```

注册成功后如后端未直接返回 Token，必须复用登录接口建立会话。

### 首页

首页是资产驾驶舱。

必须包含：

```text
顶部问候
总资产卡
收支快览
账户资产摘要
投资摘要
AI 今日总结
最近流水
```

规则：

```text
总资产必须最突出
金额必须支持隐藏
首页不要堆大量图表
最近流水最多展示 5 条
投资收益不要统一叫今日收益
```

### 记账页

记账页使用日历视图。

必须包含：

```text
年月切换
日历视图
当天收入
当天支出
当天结余
当天流水列表
记一笔入口
```

禁止：

```text
不要在记账主页面放本月支出分类占比
不要把分类统计塞进主记账页
```

### 流水录入页

必须包含：

```text
收入 / 支出 / 转账切换
金额输入
分类选择
账户选择
时间选择
备注
图片附件入口
保存按钮
```

规则：

```text
金额必须大于 0
账户必选
分类必选
时间默认当前时间
不做标签功能
```

### 账户页

账户页只展示账户相关内容。

账户类型：

```text
现金
银行卡
支付宝
微信
信用卡
其他
```

禁止：

```text
不要把投资资产混入账户页
不要把账户和投资混成一个列表
```

### 投资页

投资类型：

```text
基金
股票
虚拟货币
其他
```

收益口径：

```text
基金：昨日收益
股票：今日收益
虚拟货币：24h 收益
总投资：分项展示，不强行合并为今日收益
```

禁止：

```text
不要把基金收益写成今日收益
不要把所有投资统一按一个口径展示
不要在 App 端计算最终资产收益
最终收益以后端返回字段为准
```

### 预算页

必须包含：

```text
本月预算总览
分类预算列表
预算预警
预算编辑入口
```

状态颜色：

```text
正常状态用绿色
接近超支用橙色
已超支用红色
```

### AI 报告页

AI 报告页不是聊天页。

必须包含：

```text
今日报告
月度报告
异常消费
投资变化
预算风险
可执行建议
```

规则：

```text
报告内容要短
建议必须可执行
不要写空话
不要提供投资买卖建议
```

### 我的页

必须包含：

```text
用户信息
账户管理
分类管理
预算管理
AI 报告
设置
关于 XOAssets
```

### 设置页

必须包含：

```text
金额隐藏
深色模式预留
清理缓存
退出登录
版本信息
```

危险操作需要二次确认。
